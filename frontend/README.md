# Сигнал — веб-интерфейс

React + Vite. По умолчанию работает на моковых данных (рандом, детерминированный по запросу).

```bash
npm install
npm run dev            # http://localhost:5173, моки
```

Подключение реального бэкенда (FastAPI на :8000, запросы `/api/*` проксируются):

```bash
VITE_MOCK=0 BACKEND_URL=http://localhost:8000 npm run dev
```

Контракт `GET /api/search` и `GET /api/graph` (граф из Neo4j) описан в `src/api.js`.
Экраны: главная → сканирование → ТОП-15 + статистика + карта сигналов + отсеянные → страница-отчёт по сигналу (с экспортом в PDF через печать).
