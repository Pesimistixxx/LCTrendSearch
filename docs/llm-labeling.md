# Предварительная LLM-разметка исторических срезов

Это **псевдометки для проверки человеком**, а не независимая экспертная истина.
Они пишутся в отдельный JSONL и не подмешиваются в `prepare`/обучение
CatBoost и HGT. Файл организаторов содержит только 100 положительных
примеров на сентябрь 2026 года. Команда использует их как примеры стиля
узкой технологической ниши, но не назначает совпадающим технологиям метки.
После такого использования проверка на тех же 100 строках не будет
независимым тестом; для него нужен отдельный нетронутый набор.

Сначала локально добавьте в игнорируемый Git-файл `.env`:

```dotenv
LLM_PROVIDER=gigachat
GIGACHAT_CREDENTIALS=<ваш локальный ключ>
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_CA_BUNDLE_FILE=src/lctrend/resources/russian_trusted_root_ca_pem.crt
```

Не коммитьте ключ и не передавайте его в параметрах командной строки.
Корневой сертификат НУЦ Минцифры взят из официальной публикации
`https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt`;
его SHA-256 отпечаток: `D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31`.
Проверку TLS отключать не нужно.
Проверка без обращения к модели:

```bash
.venv/bin/python -m lctrend.modeling label-llm \
  --review artifacts/full-review-2026-09-29.reviewer_1.csv \
  --reference '/Users/komputer/Downloads/100_слабых_технологических_сигналов_сентябрь_2026.xlsx' \
  --output artifacts/llm-provisional-2026-09-29.jsonl \
  --limit 10 --dry-run
```

После согласования бюджета уберите `--dry-run`, оставив небольшой `--limit`.
Повторная команда продолжит с незавершённых пар «технология — дата».
`--all-snapshots` обрабатывает все подходящие срезы вместо одного среза
с последующими документами на семейство. У каждой строки есть версия
промпта, модель, ID процитированных документов и временно разделённые
обоснования. 12- и 36-месячные исходы после незавершённого календарного
горизонта остаются `unknown`. Отсутствие последующих документов также
не превращается в отрицательный пример.

Ограничение текущей выгрузки: для каждого среза сохранены только пять
последних документов с названиями и ссылками, а не полный текст статей.
Даже хороший LLM не должен угадывать исход только по заголовкам. Поэтому
массовые уверенные 0/1 означают проблему промпта или данных, а не успех.
Перед обучением нужен аудит выборки, более полное досье из графа и
независимый контрольный набор с экспертными метками.

## Состояние запуска 29 сентября 2026

Ключ читается, TLS-подключение с корневым сертификатом проходит, но GigaChat
возвращает `HTTP 429 Too Many Requests` и на генерации (включая
`GigaChat-2-Pro`), и на запросе баланса. Заголовок `Retry-After` отсутствует.
Пилот остановлен до получения меток; пустой JSONL не означает отрицательных
примеров. Проверьте квоту и другие активные обращения этого аккаунта в
кабинете GigaChat, затем повторите команду без `--dry-run`. Если 429
сохраняется, обратитесь в поддержку GigaChat.
